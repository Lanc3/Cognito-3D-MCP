# Changelog

## 0.4.0

- Release the 3D-only integration as Cognito-3D-mcp with isolated model engines.
- Ship the Hunyuan multiview, single-image comparison, and bidirectional skills.
- Add a Windows installer, portable user-space paths, and MCP registration.
- Preserve local job history while excluding generated and private assets.
- Fix queued-job cancellation and shutdown ordering; harden dashboard requests.
- Add source distribution checks, CPU CI, and open-source contribution guidance.

The previous embedded `hy3dgen_mcp` API is superseded; see UPSTREAM.md.
